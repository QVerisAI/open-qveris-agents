Portfolio Health Check

持仓健康检查 · 交互流程图 · BeixiAI

PHASE 1 — 快速诊断（LLM 提示词分析）
Input — 客户输入持仓
客户提供持仓列表，格式不限：
股票代码（600519）、名称（贵州茅台）、或混合格式
持仓可能是金额、比例、或股数 → 系统统一转换为持仓比例 (%)
补全与确认（最多 3 步）
  • 步骤 1（条件触发：客户只给了标的没给仓位）
    每个资产的持仓比例是多少？
  • 步骤 2（始终执行）
    将 名称 + 代码(.SH/.SZ) + 比例 + 现金 汇总发给客户确认
资产名称代码占比
贵州茅台600519.SH30%
宁德时代300750.SZ25%
中证500ETF510500.SH20%
招商银行600036.SH10%
现金—15%
Output — 快速诊断报告
  • 持仓概览：行业分布、大小盘分布、资产类别构成
  • 集中度 / 重叠分析：是否过度集中于某个行业、风格或主题
  • 总体评价：一段话总结持仓整体状况和主要特征
是否进行深度分析？
否 → 结束
PHASE 2 — 深度诊断（量化技术分析）
Questions — 分析参数收集（4 个问题）
  • Q1 换仓频率
    日内 / 周度 / 月度 / 季度 / 长期持有
    → 决定拉取数据的维度（分钟~月线）和回看周期（1月~5年）
  • Q2 仓位管理风格
    择时空仓型 / 满仓轮动 / 恒定比例 / 定投渐进 / 核心+卫星
    → 决定集中度和现金仓位的判断标准
  • Q3 风险承受力
    保守 / 稳健 / 积极 / 激进
    → 决定回撤、波动率、集中度的报警阈值
  • Q4 投资期限
    <1年 / 1-3年 / 3-5年 / 5年以上
    → 决定波动容忍度和资产配置合理性判断
  • Q5 总投资金额（可选）
    客户自行输入（万元）
    → 用于计算流动性（清仓天数）。未提供则流动性板块仅展示日均成交额
Process — 量化分析引擎
根据客户参数，拉取对应维度的行情数据，
进行相关量化计算和分析
Output — 量化诊断报告
  • 相关性热力图
  • 组合风险指标汇总
  • 因子暴露雷达图
  • 关键风险点
是否需要优化建议？
否 → 结束
PHASE 3 — 优化处方（约束 + 建议生成）
Questions — 约束条件收集（3 个问题）
  • Q1 可投资范围（多选）
    A股 / ETF / 期货 / 期权 / 港股通 / 美股 / 加密货币
    → 约束建议中可推荐的品种边界
  • Q2 剩余可投资金
    满仓无余量 / 还有 10-30% / 还有 30-50% / 还有 50% 以上
    → 决定能否建议新增仓位
  • Q3 投资目标（多选）
    资产增值 / 稳定现金流 / 对冲已有风险 / 打新底仓
    → 决定优化方向和建议侧重
Output — 分层优化建议
  • Layer 1 — 零成本操作（无需额外资金或新账户）
      仓位再平衡（减持 A、增持 B）
      替换高相关性冗余持仓（用低相关标的替代）
      调整行业 / 因子暴露偏离
  • Layer 2 — 需要额外资金
      增加新资产类别以分散风险
      补充防御性持仓（债券 ETF、红利 ETF）
      建立现金缓冲仓位
  • Layer 3 — 需要新品种 / 新账户
      期权保护策略（Protective Put, Collar）→ 需期权账户
      商品对冲（黄金 / 原油期货）→ 需期货账户
      跨境分散（港股通 / 美股）→ 需相应权限
Output — 优化前后对比
